## 1. 문제 요약
- 문제 핵심:
  - 사과가 $A$개, 오렌지가 $B$개, 바나나가 $C$개, 포도가 $D$개가 있다. 다음조건을 모두 만족시켜 과일을 한개도 빠짐없이 나열하는 경우의 수를 출력하라.
  - 모든 사과는 바나나 왼쪽에 있어야 하고, 모든 사과는 포도 왼쪽에 있어야 하고, 모든 오렌지는 포도 왼쪽에 있어야 한다.
- 입력/출력 조건: 정답을 998244353으로 나눈 나머지로 출력
- 제한 조건: $1 \le A,B,C,D \le 10^6$

---

## 2. 접근 아이디어
- 자력 풀이 시도:
  - A C D배치에서 D이전 중간중간에 B를 끼워넣는 것과 A D C배치에서 D이전 중간중간에 B를 끼워넣을수 있다라는 점은 봤다.
- 막혔던 포인트:
  - 주어진 배치를 조합식으로 표현하지 못했다.
- 답지 참고 후:
  - 가장 왼쪽에 나오는 D를 기준으로 관찰을 한후 그럼 AA...ACC..CD 이런 배치가 나올텐데 저기서 B를 중간중간에 넣는 것을 중복 조합으로 계산
  - D가 처음 나온 위치에 대해서 뒤는 C,D가 아무렇게 섞이면 되니까 D를 고정하고 C를 넣는 경우를 중복조합으로 계산하면 된다.

## 3. 코드 정리
[정답 코드](./answer.py)
```py
import sys
input=sys.stdin.readline

def solve():
    a,b,c,d=map(int,input().split())
    n=a+b+c+d
    MOD=998244353
    
    fac = [1] * (n+1)
    inv_fac = [1] * (n+1)
    for i in range(2,n+1):
        fac[i] = (fac[i-1]*i)%MOD
        
    inv_fac[n]=pow(fac[n],MOD-2,MOD)
    
    for i in range(n,0,-1):
        inv_fac[i-1]=(inv_fac[i]*i)%MOD
    
    ans=0
    for i in range(c+1):
        ans = (ans + ((fac[a+i+b])*(inv_fac[b]*inv_fac[a+i]) * ((fac[c-i+d-1])*(inv_fac[c-i]*inv_fac[d-1])))) % MOD
    
    print(ans)

def main():
    t=1#int(input())
    for _ in range(t):
        solve()
main()
```

* 시간: $O(A+B+C+D)$
* 공간: $O(A+B+C+D)$

## 5. 배운 점 / 실수

* 고등학생때 공부하던 중복조합을 다시 리마인드하고 어떻게 사용되는지 알게되었다.
* 조합론 문제를 풀때는 조건을 어떻게 표현하고 이를 식으로 풀어내야 한다는 점을 알게되었다.
* 소수 mod에 대해 팩토리얼과 팩토리얼의 역원을 전처리하여 조합을 계산할 수 있다는 점을 알게되었다.
* 기준이 되는 원소를 하나 정하면, 복잡한 부분순서 조건을 기준 앞/뒤의 독립적인 조합 문제로 분리할 수 있다는 점을 알게되었다.
